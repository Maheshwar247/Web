# Umamaheshwar's Personal Website

A personal portfolio website where I introduce myself, share my
interests, and showcase the projects I am building.

## Description

This is my personal portfolio website, built from scratch using
HTML and CSS.

I created this project to learn more about web development and
to have a place where I can introduce myself, share my interests,
and showcase the projects I work on.

The website contains:

- A personal introduction
- Information about my interests
- My GitHub profile
- Projects I am working on
- Links to my GitHub profile and projects
- Responsive design for smaller screens
- Interactive buttons and hover effects

## Technologies Used

- HTML5
- CSS3

## Getting Started

### Requirements

You don't need to install any special software to view the website.

You only need:

- A modern web browser
- Git (if you want to clone the repository)
- A code editor such as VS Code (if you want to modify the website)
